# 사양서 — 리스/할부 월납입금 계산기

파일: `leasing-calculator.html` (신규, 단일 파일)
목적: 건설기계 리스·할부 조건을 넣으면 월 납입금과 총 지급액을 즉시 계산한다.

이 문서는 **Claude Code와 Codex가 함께 보는 사양**이다. 구현과 검증 모두 이 문서를 기준으로 한다.

---

## 1. 입력

| 항목 | 단위 | 비고 |
|---|---|---|
| 장비 가격 | USD | 필수 |
| 선수금 | USD 또는 % | 둘 중 하나 선택 |
| 연 이자율 | % | 0 허용 |
| 기간 | 개월 | 정수 |
| 잔존가치(balloon) | USD | 만기 일시 상환분, 0 허용 |

## 2. 출력

- 월 납입금 (USD)
- 총 지급액 = 선수금 + 월납입금 × 기간 + 잔존가치
- 총 이자 = 총 지급액 − 장비 가격
- 월별 상환 스케줄 표 (원금/이자/잔액)

## 3. 계산식

원금 `PV = 장비가 − 선수금`, 월이율 `r = 연이자율 / 12 / 100`, 기간 `n`, 잔존가치 `B`.

```
월납입금 = (PV − B / (1+r)^n) × r / (1 − (1+r)^-n)
```

## 4. 반드시 처리해야 할 경계 조건

구현자는 아래를 **모두** 처리해야 하고, 리뷰어는 **모두** 확인해야 한다.

| # | 조건 | 기대 동작 |
|---|---|---|
| E1 | 연 이자율 = 0 | 무이자 균등분할. 위 공식을 그대로 쓰면 0으로 나눈다 |
| E2 | 기간 = 0 또는 음수 | 계산하지 않고 입력 오류 안내 |
| E3 | 선수금 ≥ 장비 가격 | 계산하지 않고 입력 오류 안내 |
| E4 | 잔존가치 ≥ 원금 | 계산하지 않고 입력 오류 안내 |
| E5 | 빈 입력 / 문자 입력 | `NaN`이 화면에 절대 노출되지 않을 것 |
| E6 | 음수 입력 | 거부 |
| E7 | 장비가 = 0 | 거부 |
| E8 | 매우 긴 기간(예: 600개월) | 지수 계산이 오버플로·정밀도 손실 없이 동작 |

## 5. 표시 규칙

- **계산은 반올림하지 않은 값으로 진행하고, 화면에 찍을 때만 소수 2자리로 반올림한다** (AGENTS.md §2)
- 통화는 천 단위 구분 기호 표시
- 상환 스케줄 마지막 달 잔액은 **정확히 0 또는 잔존가치**여야 한다. 누적 오차가 남으면 안 된다
