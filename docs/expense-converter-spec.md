# 사양서 — 출장비 정산 환산기

파일: `expense-converter.html` (신규, 단일 파일)
목적: RUB·USD·KRW가 섞인 출장 영수증을 하나의 정산통화로 환산해 항목별 소계와 총계를 낸다.

이 문서는 **Claude Code와 Codex가 함께 보는 사양**이다. 구현과 검증 모두 이 문서를 기준으로 한다.

---

## 1. 입력

**영수증 행** (여러 건, 추가·삭제 가능)

| 항목 | 형식 | 비고 |
|---|---|---|
| 날짜 | YYYY-MM-DD | |
| 분류 | 항공권 / 숙박 / 교통 / 식대 / 기타 | 선택 |
| 통화 | RUB / USD / KRW | 선택 |
| 금액 | 숫자 | 해당 통화 기준 원금액 |

**정산 설정**

| 항목 | 비고 |
|---|---|
| 정산통화 | RUB / USD / KRW 중 선택 |
| 환율 | 정산통화가 아닌 각 통화에 대해 입력 |

## 2. 환율 의미 — 반드시 이 방향으로 해석할 것

환율 입력란은 **`1 <정산통화> = ? <원통화>`** (정산통화/원통화)를 뜻한다. 환산액 = 원금액 ÷ 환율.

예) 정산통화가 USD이고 `1 USD = 80 RUB` 로 입력하면,
`10,000 RUB → 125.00 USD` 가 되어야 한다. (방향을 뒤집으면 800,000.00 USD가 나온다)

나누어떨어지지 않는 경우도 확인한다: `1 USD = 95.24 RUB` 이면 `10,000 RUB → 105.00 USD` (원값 104.9979…).

> 이 방향을 뒤집어 구현하면 결과가 그럴듯한 숫자로 나오면서 완전히 틀린다.
> 리뷰어는 실제 수치를 대입해 방향을 검산하라.

## 3. 출력

- 분류별 소계 (정산통화)
- **총계** (정산통화)
- 통화별 원금액 소계 (환산 전 원통화 그대로)
- 결과 표를 클립보드로 복사하는 버튼 (엑셀 정산 양식에 붙여넣기용)

## 4. 반드시 처리해야 할 경계 조건

구현자는 아래를 **모두** 처리해야 하고, 리뷰어는 **모두** 확인해야 한다.

| # | 조건 | 기대 동작 |
|---|---|---|
| E1 | 환율이 0 또는 미입력 | 환산하지 않고 해당 행에 오류 표시. 총계에 `NaN`·`Infinity` 금지 |
| E2 | 환율 방향 | §2 예시(`10,000 RUB ÷ 80 = 125.00 USD`, `10,000 RUB ÷ 95.24 = 105.00 USD`)가 정확히 나올 것 |
| E3 | 반올림 시점 | **건별로 반올림하지 말 것.** 원값으로 합산하고 표시할 때만 반올림. 분류별 소계의 합이 총계와 1원(전) 단위까지 일치해야 한다 |
| E4 | KRW 표시 | KRW는 소수점 없이 정수로 표시. RUB·USD는 소수 2자리 |
| E5 | 원통화 = 정산통화인 행 | 환율 없이 그대로 합산 (환율 입력란을 요구하지 말 것) |
| E6 | 빈 행 / 문자 입력 | 무시하거나 오류 표시. `NaN`이 화면에 절대 노출되지 않을 것 |
| E7 | 음수 금액 | 환불·차감으로 허용하되 총계에 정상 반영 |
| E8 | 영수증 0건 | 총계 0. 오류가 아니다 |
| E9 | 행 삭제 | 삭제 즉시 모든 소계·총계가 재계산될 것 |

## 5. 검산 요구사항

화면 어딘가에 **검산 표시**를 둔다.

```
분류별 소계의 합 === 총계
```

두 값이 다르면 눈에 띄게 경고한다. E3 버그가 있으면 여기서 드러난다.

## 8. 영수증 사진 인식 (추가 기능)

사진을 첨부하면 영수증 행을 만들고 **통화·금액·날짜**를 자동으로 채운다.

- OCR은 브라우저 안에서 Tesseract.js(러시아어·영어·한국어)로 한다. **사진은 외부로 전송하지 않는다.** 라이브러리와 언어 데이터만 CDN에서 받는다
- 라이브러리는 사진을 첨부할 때 처음 불러온다. 불러오지 못하면(오프라인 등) 오류를 표시하고, 나머지 계산 기능은 영향받지 않는다
- 금액: `ИТОГО`·`К ОПЛАТЕ`·`TOTAL`·`합계`·`결제금액` 등 합계 키워드가 있는 줄의 숫자를 우선한다. 없으면 가장 큰 금액을 **추정값**으로 쓰고 그렇다고 표시한다
- 숫자 형식: `1 234,56`(러시아식), `1,234.56`, `12,000`(KRW)을 모두 해석한다
- 통화: `₽`·`руб`·`$`·`USD`·`₩`·`원` 등 기호를 우선하고, 없으면 문자 체계(키릴→RUB, 한글→KRW)로 추정한다
- 인식 결과는 **초안**이다. 행 아래에 사진 미리보기와 인식 내용을 보여주고 사용자가 확인·수정한다. 찾지 못한 항목은 비워 두고 알린다
- 인식 중에 행을 삭제해도 오류가 나지 않아야 한다
