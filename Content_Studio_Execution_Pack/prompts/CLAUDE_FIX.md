# Claude Code 수정·재검토 지시문
Claude 독립 검토 보고서와 해당 BASE/HEAD를 확인하고 findings를 재현하라(D42 — Codex는 쓰지 않는다).
P0/P1 및 실패 수용 조건부터 최소 변경으로 수정한다. 보고서가 틀렸다고 판단하면 코드·재현 결과로 근거를 제시하고 무조건 따르지 않는다.
테스트를 삭제/약화하거나 승인·인증·중복 방지 기능을 끄지 않는다. 관련 없는 리팩터링을 추가하지 않는다.
수정 결과와 회귀 테스트(수정을 되돌리면 실패하는지 변이 확인 포함)를 기록하고 새로운 HEAD를 commit한다. 기존 리뷰 pass를 재사용하지 않는다.
어떤 finding이 어떤 변경과 테스트로 해결됐는지 표를 작성하고, 보완분은 새 컨텍스트의 Claude 검토자로 짧게 재검토한다.
실제 계정·API 권한이 없어 못 한 일은 미검증으로 표시하고 가능한 mock/로컬 작업을 마친다.
