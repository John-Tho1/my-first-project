# Claude Code 첫 실행 지시문

이 폴더의 개인 콘텐츠 스튜디오 앱을 주 구현자로 개발하라.
먼저 AGENTS.md, CLAUDE.md, README_KO.md, docs/01_PRODUCT_AND_UX.md, docs/02_ARCHITECTURE.md,
docs/04_DATA_AND_API.md, docs/05_BACKLOG_AND_ACCEPTANCE.md, docs/06_AGENT_WORKFLOW.md를 읽어라.

목표는 메모·URL·음성을 모으고 질문과 AI 보조로 초안을 완성하며, 원본을 보유하고 사용자가 승인한 채널별 버전만 배포하는 개인 앱이다.
독자는 해외 사업·영업 실무자/관리자와 해외 근무 관심자이고, 별도 이름으로 운영한다.
현재 패키지는 설계이며 앱 코드나 실제 연결이 존재한다고 가정하지 마라.

이번 첫 세션 범위:
1. T00 환경·기존 저장소 상태 확인. 사용자에게 비밀값을 붙여넣으라고 하지 말고 설치·인증 유무만 확인한다.
2. 기존 코드/AGENTS가 있으면 보존하고 차이·충돌을 보고한다. 없으면 현재 작업 폴더에서 새 개인 앱 구조를 만든다.
3. M0+M1만 작업별로 구현한다. 우선 T01 구동+mock, 이후 수집→저장→검색→수정→export/restore의 수직 흐름.
4. 외부 연결이 없어도 진행하라. UI 기본값은 한국어, MSK 표시, LLM mock, publish disabled, collectors disabled.
5. 각 작업의 의미 있는 테스트를 실행하고 실제 결과와 사용자가 볼 수 있는 실행 방법/화면을 제시한다.
6. 코드 commit 후 BASE/HEAD와 IMPLEMENTATION_HANDOFF를 준비하고 Codex 검증 경계에서 멈춘다. 검증자가 연결돼 있지 않으면 인계자료를 만들고 미검증임을 밝혀라.
7. M2 이후를 임의로 한 번에 구현하거나 공개 배포하지 마라.

다음은 이후 사용자의 구체 승인이 필요하다: 실제 OAuth 연결, 외부 자료 가져오기, API 과금 발생 live 호출, SNS/YouTube 시험 포함 업로드·게시, 운영 배포·유료 인프라.
기존 세션에서 정확히 승인된 범위가 있으면 반복 확인하지 말고 그 범위와 근거를 기록한다.

선택이 필요한 기술은 M0에서 현재 공식 자료와 환경에 맞춰 하나를 고르고 docs/ENVIRONMENT.md에 근거를 남겨라.
불필요한 기능 추가보다 수집과 작성의 부담을 줄이는 작동하는 흐름을 먼저 완성하라.
