# 테스트 케이스 — 출장비 정산 환산기 (E1~E9)

대상: `expense-converter.html` · 기준: `docs/expense-converter-spec.md` §4

- **자동**: headless Edge에서 계산 함수(`calculate`)와 실제 페이지 DOM을 구동해 확인한 항목. 테스트 스크립트는 저장소에 포함되어 있지 않다.
- **수동**: 브라우저에서 직접 입력해야만 재현되는 항목. 2026-09-21 사용자가 브라우저에서 확인해 모두 통과(PASS).
- 표기: 환율은 `1 정산통화 = ? 원통화` (환산액 = 원금액 ÷ 환율). 정산통화를 명시하지 않은 케이스는 USD.

## 상세

### E1 — 환율이 0 또는 미입력

| ID | 입력 | 기대 결과 | 방식 |
|---|---|---|---|
| E1-1 | RUB 10,000 / RUB 환율 비움 | 행: `⚠ 환율 미입력 (RUB→USD)` · 총계 `0.00 USD` · 경고 "오류가 있는 영수증 1건은 소계·총계에서 제외" | 자동 |
| E1-2 | RUB 10,000 / RUB 환율 `0` | 행: `⚠ 환율이 0입니다 (RUB→USD)` · 총계 `0.00` | 자동 |
| E1-3 | RUB 환율 `-1` | 행: `⚠ 환율은 양수여야 합니다 (RUB→USD)` | 자동 |
| E1-4 | USD 50 + RUB 100(환율 `-1`) + KRW 1,000(환율 비움) | 반영 1건 · 오류 2건 · 총계 `50.00` | 자동 |

공통 확인: 화면 어디에도 `NaN`·`Infinity`·`undefined`가 나오지 않는다.

### E2 — 환율 방향

| ID | 입력 | 기대 결과 | 방식 |
|---|---|---|---|
| E2-1 | RUB 10,000 / 1 USD = 80 RUB | 행 `125.00 USD` · 총계 `125.00 USD` (방향이 반대면 800,000.00) | 자동 |
| E2-2 | RUB 10,000 / 1 USD = 95.24 RUB (나누어떨어지지 않음) | 총계 `105.00` (원값 104.9979…) | 자동 |
| E2-3 | 금액 `1e4` / 환율 `9.524e1` (지수 표기) | 총계 `105.00` | 자동 |

### E3 — 건별 반올림 금지, 소계 합 = 총계

| ID | 입력 | 기대 결과 | 방식 |
|---|---|---|---|
| E3-1 | 5개 분류에 USD 0.005씩 | 총계 `0.03` (원값 0.025를 반올림). 건별로 반올림하면 0.05가 되므로 이 값이 나오면 버그 | 자동 |
| E3-2 | E3-1과 같음 | 분류별 소계 표시값의 합 = `0.03` = 총계. 검산 `✓ 일치` | 자동 |
| E3-3 | 같은 분류에 RUB 0.1, 0.2 / 환율 1 | 원값 합이 정확히 0.3 (부동소수점 오차 없음) | 자동 |
| E3-4 | 무작위 영수증 1~12건 × 3,000세트, 정산통화 3종 순환 | 모든 세트에서 원값 소계 합 = 원값 총계, 표시 소계 합 = 표시 총계 | 자동 |
| E3-5 | 같은 분류에 RUB 0.01 × 6행 / 1 USD = 12 RUB | 원값 정확히 0.005 → 총계 `0.01`. 행마다 나눗셈을 반올림하면 0.00이 되므로 이 값이 나오면 버그 | 자동 |

### E6 — 빈 행 / 문자 입력

| ID | 입력 | 기대 결과 | 방식 |
|---|---|---|---|
| E6-1 | 금액 비움 | 행 `—`, 합계에서 무시. 오류 아님 | 자동 |
| E6-2 | 금액 `abc` | 행 `⚠ 금액이 숫자가 아닙니다` · 합계 제외 | 자동 |
| E6-3 | 금액 소수 21자리 (`0.123456789012345678901`) | 오류 (`소수 자릿수가 너무 깁니다`). 초과 자리가 모두 0이면 허용 | 자동 |
| E6-4 | 지수 한계: `1e-20` 허용, `1e-21`·`10e-23`·`1e999` 오류 | 기대대로 허용/오류 | 자동 |
| E6-5 | 입력란에 미완성 값 `1e-` 또는 `-` 타이핑 | 행 `⚠ 금액이 숫자가 아닙니다`, `NaN` 미노출 | **수동 PASS** — 스크립트로는 브라우저의 badInput 상태를 만들 수 없어 수동 확인 |
